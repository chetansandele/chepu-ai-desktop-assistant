# Setup Guide

Chepu AI Desktop Assistant is a Windows PC voice assistant project.

## Requirements

- Windows 10/11
- Node.js
- Git
- VS Code

## Planned Setup

1. Clone the repository.
2. Install dependencies using npm.
3. Run the development server.
4. Start the Electron desktop app.

## Commands

npm install  
npm run dev
