# Safety Policy

Chepu AI is designed to be safe, transparent, and privacy-friendly.

## Allowed Actions

Chepu AI can help with:

- Opening apps
- Opening websites
- Creating files and folders
- Opening folders
- Helping with coding
- Reading basic system information
- Friendly AI conversation
- Productivity tasks

## Actions Requiring Confirmation

Chepu AI should always ask confirmation before:

- Deleting files
- Sending emails
- Shutdown or restart
- Running system commands
- Installing software
- Changing important settings
- Accessing sensitive folders

## Not Allowed

Chepu AI should not:

- Steal passwords
- Read or store OTPs
- Handle UPI PINs
- Access banking secrets
- Perform hidden recording
- Track users secretly
- Send messages without confirmation
- Delete data without confirmation
- Upload private files without permission

## Privacy First

Chepu AI should always respect user privacy and ask permission before sensitive actions.
