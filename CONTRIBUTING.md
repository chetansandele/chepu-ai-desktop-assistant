# Contributing to Chepu AI Desktop Assistant

Thank you for your interest in contributing to Chepu AI.

Chepu AI is an open-source Hindi/Hinglish desktop voice assistant focused on Windows PC automation, productivity, coding help, and safe AI interaction.

## How You Can Contribute

You can contribute in the following areas:

- React/Electron desktop UI
- Hindi/Hinglish voice command examples
- PC automation logic
- Documentation improvements
- Bug fixes
- Testing on Windows devices
- Safety and privacy improvements
- AI assistant personality improvements
- Coding assistant features

## Contribution Rules

Please follow these rules:

1. Keep the project safe and privacy-friendly.
2. Do not add features that steal passwords, OTPs, UPI PINs, or private data.
3. Do not add hidden recording, tracking, or spying features.
4. Ask user confirmation before risky actions like file deletion, shutdown, restart, email sending, or system changes.
5. Write clean and understandable code.
6. Explain your changes clearly in pull requests.

## Pull Request Guide

When creating a pull request, please include:

- What feature or bug you fixed
- Screenshots if UI changed
- Testing details
- Any known limitations

## Project Vision

The vision of Chepu AI is to create an open-source Hindi/Hinglish AI desktop assistant that helps users control their Windows PC naturally through voice.

Thank you for helping improve Chepu AI.
